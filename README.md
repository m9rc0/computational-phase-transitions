# computational-phase-transitions
The idea is to make simulations on random systems and try to investigate the phase transition that happen. 
For now the main reference is the book by Moore "The Nature of Computation"

**Random 3-SAT**
For now the plan is:

	- [ ] create a function that implements backtracking to solve a 3-SAT problem
	- [ ] find a way to make random 3-SAT problems with n variables and m clauses
	- [ ] use what has been done to investigate the phase transition
